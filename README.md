# Badger Icon Generator

A lightweight React application for creating 24×24 pixel icons. Start from any emoji or single character, paint directly onto the grid with your chosen colour, and export the result as a transparent PNG.

## Getting started

```bash
npm install
npm run dev
```

The development server runs on <http://localhost:5173> by default.

## Features

- **Emoji bootstrap** – drop any emoji onto the 24×24 grid as a starting point.
- **Pixel-perfect painting** – choose a brush colour, toggle to the eraser, and drag to paint or remove pixels.
- **Live preview** – see your icon scaled up while you draw.
- **Transparent PNG export** – download your creation at the native 24×24 size with a transparent background.

## Available scripts

- `npm run dev` – start the local development server.
- `npm run build` – create an optimised production build.
- `npm run preview` – preview the production build locally.
- `npm run lint` – run ESLint across the project.
