# Badger Icon Generator

Create playful 24×24 pixel icons with React. Start from any emoji or character, draw with a custom colour palette, and export a crisp PNG with a transparent background.

## Features

- **Emoji seeding** – type an emoji or glyph to instantly rasterise it onto the 24×24 grid.
- **Pixel-perfect editor** – paint or erase individual pixels with live preview scaling.
- **Transparent exports** – download exactly what you see as a PNG ready for use anywhere.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL to launch the editor.

To produce a production bundle:

```bash
npm run build
```

## Exporting icons

Use the **Export PNG** button to download a 24×24 PNG that preserves transparency. The preview canvas always renders at 24×24 pixels while scaling cleanly for inspection.
