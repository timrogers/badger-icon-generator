# 24×24 Icon Generator

A React-based web application for creating 24×24 pixel icons with a transparent background.

## Features

- **24×24 Pixel Grid**: Draw icons pixel by pixel on an interactive grid
- **Emoji/Character Input**: Enter an emoji or character to render it onto the grid
- **Color Picker**: Select any color to draw with
- **Drawing Mode**: Click and drag to draw directly on the grid
- **Clear Grid**: Reset the canvas to start over
- **PNG Export**: Export your icon as a PNG file with transparent background

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Usage

1. **Drawing Mode**: Select a color using the color picker and click/drag on the grid to draw
2. **Emoji Mode**: Enter an emoji or character in the input field and click "Render" to convert it to pixels
3. **Export**: Click "Export PNG" to download your icon as a 24×24 PNG file with transparency

## Technologies

- React 19
- Vite
- CSS3
